# 个人简历 CSS 样式设计实验报告

## 一、实验目的

1. 参考专业简历形式，为个人简历添加 CSS 样式，实现字体、颜色、边距、背景等基本样式
2. 将 CSS 样式单独写在.css 文件中，体会 CSS 的分离式控制能力
3. 使用合理的图片路径，确保图片可正常加载
4. 梳理并记录实验过程中的流程

## 二、实验流程

### 1. 分析参考简历布局

参考简历采用**现代渐变风格左右两栏布局**：
- **左侧边栏**（渐变紫蓝色背景）：包含圆形照片、姓名、求职目标、联系方式、技能进度条、兴趣爱好
- **右侧主内容区**（白色背景）：包含教育背景、工作经历、项目经验、其他技能、自我评价
- **分隔线**：使用渐变透明分隔线增加层次感

## 三、实验内容

### 1. 颜色方案

- **主色调**：渐变紫蓝色 (#667eea → #764ba2)
- **强调色**：紫色 (#764ba2)
- **白色**：用于文字、进度条、分隔线
- **背景色**：渐变背景 + 白色主内容区

### 2. 布局设计

- **整体布局**：Flexbox 左右两栏
- **左侧边栏**：固定宽度 320px
- **右侧主内容区**：flex: 1 自适应
- **响应式布局**：小屏幕时变为单栏

### 3. 视觉效果

- **渐变背景**：页面背景和侧边栏使用紫蓝渐变
- **圆形照片**：130px 圆形头像
- **进度条**：白色半透明背景 + 白色填充
- **分隔线**：渐变透明分隔线
- **时间标签**：渐变背景的胶囊标签

## 四、遇到的问题及解决方案

### 问题 1：左右两栏高度不一致
- **问题**：侧边栏和主内容区高度不匹配
- **解决**：使用 `overflow: hidden` 让容器自适应内容高度

### 问题 2：侧边栏内容过多导致布局混乱
- **解决**：调整侧边栏宽度和内边距，优化内容分布

### 问题 3：技能进度条显示不清
- **解决**：使用白色进度条配合深色背景，增强对比度

### 问题 4：兴趣爱好在小屏幕上显示不佳
- **解决**：使用 flex-wrap 实现自动换行
